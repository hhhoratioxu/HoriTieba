## 性能测量

数据量：10000 帖、2500 条输入日志（裁剪为 2000 条）、5×5000 条内容、20 次增量更新。

| 测量               |    本次实测 |
| ------------------ | ----------: |
| 数据准备与日志裁剪 |  1692.26 ms |
| 后台分页快照       |    81.44 ms |
| 当前页快照大小     | 11423 bytes |
| 单条增量更新平均   |    14.28 ms |

环境为 Node + fake-indexeddb，darwin/arm64。这是数据层测量，不是实际浏览器 IndexedDB 吞吐、帧率、内存泄漏或长期挂机证明。界面每页渲染 25 条，不传其他库的大数组。
