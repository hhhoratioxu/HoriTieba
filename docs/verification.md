# 验证记录

## 0.4.1 新帖监控修复

在品牌 Chrome 中只读核对了这个故障。列表页同时出现了「创建时间」和「最后回复时间」。有的新主题能从一楼核实创建时间，有的仍在列表、点开已是贴吧删帖页。旧版工作页停在删帖页时，记录中出现连续读取失败和整轮延期，发送尝试为零。

本地回归覆盖旧帖优先排除、发现后滑出列表、单帖退避、删帖、工作页关闭、账号与安全验证、提交后结果未知。隔离浏览器使用回环 HTTPS 站点验证实际扩展的发表按钮和定时器。真实账号没有为本次修复新发评论。[列表测试](evidence/forum-e2e.json) · [Chrome 记录](chrome.md)

## 0.4.0

品牌 Chrome 上已核对真实列表和具体帖子各自的一行输入栏、工具栏直接定位、输入启用和清空恢复禁用。真实发布 0 条。[实机记录](chrome.md)

隔离浏览器中另行验证了以下流程。

- 从贴吧列表直接启动，现有主题成为基线，四个可核实的新帖各收到一条一级评论。新帖滑出列表后仍能完成核实，旧帖被顶起没有触发发送。四次模拟发布均在仅监听本机的 HTTPS 站点完成。[列表测试](evidence/forum-e2e.json)
- 帖子页逐条回复一级评论和楼中楼，同一作者的不同原评论分别处理。翻页、发现后来新增的评论、停止后去重和结果未知保护均已验证。[帖子测试](evidence/thread-reply-e2e.json)
- 两页可同时运行，关闭其中一页仅停止对应任务。模拟站点测试没有使用真实贴吧账号发布。
