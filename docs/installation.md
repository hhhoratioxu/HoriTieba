# 安装、更新与移除

从 [GitHub Releases](https://github.com/hhhoratioxu/HoriTieba/releases/latest) 下载 `HoriTieba-extension.zip`。

本构建是开发者模式加载的浏览器扩展，不是商店安装包。只针对桌面浏览器设计，品牌 Chrome 的已执行结果见 [Chrome 验收](chrome.md)，Edge 尚未独立验收。

## 从 Release 安装

1. 解压 `HoriTieba-extension.zip`，将整个 `HoriTieba-extension` 文件夹放在长期保留的位置。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启开发者模式，点击“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json`、`dashboard.html`、`background.js` 的文件夹。不要选择 ZIP 文件，也不要只选择 `assets`。
5. 登录贴吧，打开或刷新一篇具体帖子，底部会显示「本帖自动回复」。控制台入口可固定工具栏图标。点击图标后打开完整控制台；也可以从扩展详情的“扩展程序选项”进入。

不需要启动 Node.js、运行开发服务器、安装 Python 或购买任何服务器。管理控制台地址以 `chrome-extension://` 开头，资源来自扩展本身。

如果侧边栏 API 不可用，入口会回退到完整控制台。侧边栏页面关闭不终止任务；后台是唯一调度者。浏览器完全退出和电脑关机则无法运行。

## 演示与真实模式

初次打开默认演示模式。演示库附带明确标注的本地内容，模拟帖子不是实际贴吧链接。真实模式内容库为空，默认只读观察。需要自动发布时，在设置中选择“自动首评与追评”，导入真实内容库并保存；启动前核对实际账号、目标贴吧、内容、追评阶段和数量摘要。

真实模式最多复用一个监控页和一个执行页，不刷新用户原来正在阅读的页面。自动模式会使用贴吧官方“旧版”切换入口，这可能改变同一浏览器资料的贴吧版式偏好。若隐藏页未能准备好回复框，0.2.2 会自动显示自己的执行标签页并重试。请保留这个工作页。执行页只在没有草稿时导航或刷新；如果工作页有草稿、离开目标贴吧或被关闭，会显示具体原因。出现安全验证时通过“打开工作标签页”由用户处理，扩展不会求解或绕过验证码。

自动模式只处理启动基线之后且创建时间能够确认的新主题，不会对当前已存在的帖子批量补发。关闭浏览器或电脑休眠会延后计划；恢复时先检查未完成的发送。

## 更新与备份

更新前先导出内容配置及历史。停止运行后用新构建替换原文件夹内容，再在扩展管理页点击“重新加载”。更新后未知发送必须先核实；干净的运行会保留计划但不会补发错过的所有时刻。数据库升级被旧页面占用时应关闭旧控制台，不要删除数据库来解决。

卸载扩展会删除该浏览器资料中的本地数据。不同浏览器或不同资料之间不会自动同步。JSON 内容配置包不包含会话或密码；历史与日志需分别导出。

## 平台验收边界

macOS Safari 使用单独的 `HoriTieba-safari.zip`，按 [Safari 安装与验收](safari.md) 通过“添加临时扩展”加载，不使用 Chrome 的安装页面。已实际验证 Safari 27.2 的临时安装、控制台、本地存储、后台演示、真实新主题发现与自动首评。真实追评响应超时后仍为未知，没有重发，原批次已停止；完整真实自动发布验收未通过。

另已验证 macOS arm64 上的 Playwright Chromium 156.0.8078.4 扩展加载、页面和后台流程。品牌 Chrome 156.0.8078.80 已完成本机安装、控制台、原生侧边栏、真实账号的新帖发现、自动首评及四次回复自己的追评，见 [Chrome 验收](chrome.md)。品牌 Edge、Windows、Intel Mac、Linux 和手机端均没有独立验收。不能把 Chromium 测试自动扩展为这些平台的已验证承诺。
