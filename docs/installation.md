# 安装和更新

## 首次安装

1. 在 [GitHub Releases](https://github.com/hhhoratioxu/HoriTieba/releases/latest) 下载 `HoriTieba-extension.zip`，解压到长期保留的位置。
2. 在桌面 Chrome 打开 `chrome://extensions`。开启「开发者模式」，点「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。
3. 登录贴吧，打开或刷新一个吧的帖子列表或一篇具体帖子，在底部输入内容即可。

## 更新已有版本

先停止正在运行的任务。用新版本替换原扩展目录内的程序文件，然后在 Chrome 的扩展管理页点击 HoriTieba 卡片的「重新加载」，再刷新贴吧页面。保留原目录和同一个浏览器资料，可以继续使用已有的本地记录。

0.4.0 的工具栏图标会定位到当前贴吧页的输入框。在其他网站点击图标可以打开贴吧。旧版控制台还有未结束的任务时，弹窗会提供处理旧任务的入口。
