# 怎么用

**给新帖评论**　打开想监控的那个吧，停在能看到许多帖子标题的列表页。在底部「自动评论」输入文字，点「开始」。助手先记下当前列表，然后给可以确认是启动后新建的帖子各发一条一级评论。

**给评论回复**　打开一篇具体的帖子，在底部「自动回复」输入文字，点「开始」。助手会翻页处理其他人的评论和楼中楼，也会继续看后来新增的评论。同一账号在同一帖内，每条原评论只处理一次。

保留启动该功能的标签页。点「停止」、关闭标签页或离开对应的吧或帖子即可结束。需要同时使用两项时，把具体帖子开在另一个标签页。

## 页面上暂时显示 0

列表页要等新帖出现。启动时已有的帖子和后来被顶上来的旧帖都跳过。贴吧显示的创建时间通常只精确到分钟，与启动时间在同一分钟、无法核实先后的帖子也会跳过。列表里已经发现、还在等待核实的新帖，即使稍后滑出列表也会继续检查。

帖子页会跳过自己的评论、已经处理过的评论和身份无法核实的评论。两个功能共用每个账号至少 30 秒的发送间隔。

## 遇到暂停

草稿、安全验证或登录账号改变时，先看页面底部的提示。已提交内容的结果不明确时，「核实」只检查原来的发送记录。页面中已有的草稿需自行处理。真实记录和内容保存在该浏览器资料中。
