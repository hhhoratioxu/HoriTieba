# 已知限制与未验收项

1. 0.2.2 的原生 Chrome 验收见 [C03 记录](chrome.md)。0.2.1 曾在 C01 批次修复并人工继续后完成五条评论，随后 C02 从头运行在第一条追评准备时阻断。新版本的无限期运行和不同平台页面结构仍有待实测。
2. 自动模式使用贴吧官方旧版入口，可能影响同一浏览器资料的贴吧版式偏好。新版仅只读；旧版入口不可用、结构改变或账号交叉 ID 不一致时阻断，不改走未验证私有接口。
3. 主题一楼时间只有分钟精度。初始基线旧帖不补发，与启动分钟重叠的帖子保守跳过；这可能漏掉实际在启动后数秒创建的主题。每轮最多观察 100 条列表记录并核实 2 个新增主题，未加载或扫描期间已消失的主题可能漏检，不承诺零漏帖。
4. 评论核实限于已加载分页。首评前读取尾页快照，自己的首评保存分页位置。楼中楼已有内容分页不完整、父编号不明、正文被平台改变或多个匹配时停止，不猜测回复目标或自动重复发布。
5. 楼中楼临时节点缺少独立编号时，需要一次安全刷新后才能核实；有任何草稿则不刷新，保持未知供人工处理。平台确认延迟超过本次有限核实窗口也会进入未知。
6. 扩展自动化测试运行在 Playwright Chromium 156.0.8078.4、macOS arm64；Safari 27.2 另完成原生临时安装、后台演示、真实新帖发现和自动首评，追评因响应超时保持未知，完整真实链路未通过。品牌 Chrome 156.0.8078.80 的原生侧边栏、配置导入、真实账号预检及首评加四次追评通过。品牌 Edge、Windows、Linux、Intel Mac 与长期运行兼容性未独立验收。侧边栏 HTML 页面本身已测试。
7. 没有后台常驻、关机运行或精确秒级调度保证。扩展卸载会清除数据。更新、后台回收或工作页关闭可能让未完成发送进入未知，必须先核实。
8. 外部发布无法与 IndexedDB 构成原子事务。人工强制重试仍可能产生重复；持久化单次点击记录、状态核实和未知占额度用于降低风险，不能保证平台绝对恰好一次发布。
9. 控制台的自动追评只开放“回复自己的首评”。“回复上一条追评”和绑定已有首评没有开放；不会静默换成回复其他用户或新一级楼层。
10. 每次保存内容库生成新版本并从游标 0 开始，下次运行生效。当前运行不热替换文本；库耗尽后应停止、调整并确认新批次。
11. TXT 一行一条，不保留多段条目的边界；请用 JSON 完整导出。导入上限 20 MB、每库 5000 条、单条 2000 字符。这些是产品约束，不是贴吧官方阈值。
12. 观察缓存和日志有界，但带任务证据的历史及去重标记不会被自动删除。需定期备份并清理历史；长期大量任务的磁盘增长未测。性能测量来自明确列出的合成数据，不代表零卡顿或无内存泄漏。
13. 初始数据库 schema 为版本 1，具备升级入口和失败提示，但没有已验收的历史 schema 迁移路径。旧配置缺失 realAction 时按只读处理。没有后台服务或云备份。
14. 没有商店上架、CRX 签名分发、自动更新渠道或手机安装包。Release ZIP 需要解压后通过开发者模式加载。
15. Safari 构建为本机临时扩展，退出 Safari 或 24 小时后会移除；不等于签名容器应用或 App Store 分发。Safari 更新扩展时会改变临时扩展地址和工作标签页标识，旧绑定按失效处理，需从控制台恢复并重新检查。

0.3.0 的帖子底部入口独立于控制台，覆盖当前账号以外的评论和楼中楼。它使用贴吧提供的完整楼层和分页，无法访问平台隐藏、已删除或无可核对身份的内容。该模式的实际发言需单独验收。
